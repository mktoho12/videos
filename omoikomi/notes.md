## motion-kit への提案

motion-kit に還元したい知見を書く。動画固有の文言・ブランド・素材は書かない。

| 種別（工程 / 文法 / 部品 / 雛形） | 内容 | 根拠（この動画で何が起きたか） |
|---|---|---|
| 工程 | 段階0のブリーフに「メッセージを見せる具体例（2〜3個、別々の角度）」の欄を足す。素材の会話をなぞると、例が1つの流れになり、伝わりにくい | 公開した2本を見返したユーザーの指摘（2026-10-20） |
| 文法 | カメラ（話す人への寄り・引き・差し込み場面への切り替え）の決まりを文法に足す。寄りの倍率・切り替えの所要時間・どの台詞で寄るかの規則 | 前の2本は画角がずっと同じで単調だった（ユーザーの指摘） |
| 文法 | 本編と最後のあいさつの間に「本編おわり」の合図（効果音＋間）を置くことを、終わりの作り方の決まりに足す | アニマティック v1 で、本編とあいさつがつながって見えた（ユーザーの指摘、2026-10-20） |
| 部品 | シーンごとに BGM を切り替える部品（曲の表・クロスフェード・曲ごとの音量そろえ）を kit に入れる。また、本編おわりの合図（効果音＋間＋本編と違う曲）を「終わりの作り方」として工程か文法に入れる | この動画で BGM の切り替えと、あいさつ用の曲を自前で書いた（ユーザーの指示、2026-10-20） |
| 工程 | 完成前に、作っていない人に見てもらう段階を入れる（「何の話だった？」「どこで退屈した？」の2問） | 作り手だけでは伝わりやすさを判断しにくい（2026-10-20 の相談） |
| 工程 | 段階6で曲を決めたら、承認の前に YouTube へ非公開でアップロードして、初期チェック（Content ID）を通しておく。申し立てが付いた曲はその場で替える | 承認後のアップロードで S4 の曲に申し立てが付き、書き出しと承認をやり直した（2026-10-20） |
