# ずんだもん動画の決め事

チャンネル「ずんだもんのシェアハウス暮らし」の動画に共通する決め事です。動画を重ねるうちに変わったものは、いまの形で書いています。それぞれの動画で決めた経緯は、各動画の `brief.md`・`styleframe.md`・`notes.md` にあります。

新しい動画を作るときは、段階0（ブリーフ）の前にこのファイルを読みます。工程は motion-kit の `docs/workflow.md` に従いますが、食い違うところはこのファイルを優先します。いま食い違っているのは次の2つです。

- **長さ**：workflow.md は段階0で尺（秒）を決め、段階1でそれに合わせるとしています。掛け合い動画では長さを決めません（下の「素材と長さを、内容の制約にしない」）
- **台本と声**：workflow.md には台本と声の段階がありません。掛け合い動画では、段階1で構成を選んだあとに台本を書き、VOICEVOX で合成して試聴し、確定してから段階2に進みます

## 新しい動画の始め方

motion-kit の雛形（`src/templates/`）は、モーショングラフィックス用です。台本・声・立ち絵・字幕・画角・BGM の仕組みが入っていません。掛け合い動画は、いちばん新しい動画を複製して始めます。

- 横長の動画は `hitorigoto/`、ショート（縦長）は `hanauta/` を複製する（2026-10-23 時点でいちばん新しいもの）
- 新しいフォルダ `<slug>/` に、次のものを複製する

| 複製するもの | そのまま使う／書き直す |
|---|---|
| `package.json`・`package-lock.json`・`tsconfig.json`・`remotion.config.ts` | `package.json` の `name`・`description` を直す。制作中は motion-kit を `"file:../../motion-kit"` にして `npm install`（隣に motion-kit を clone しておく。README の「新しい動画を作る」）。完成したら motion-kit のタグに固定する |
| `tools/synth_voice.py` | そのまま。`script.md` の台詞を合成し、`public/voice/` と `src/lines.json` を作る |
| `src/Tachie.tsx`・`src/Caption.tsx`・`src/font.ts`・`src/timeline.ts`・`src/index.ts` | そのまま（`index.ts` の冒頭のコメントだけ直す） |
| `src/style.ts` | **複製したらすぐ `frame` を `{ width: 0, radius: 0 }` にする**（下の「画面」の枠の話）。段階2 で、配置や倍率をこの動画に合わせて直す |
| `src/Root.tsx` | コンポジションの名前と、スタイルフレームの一覧を直す |
| 本体（`src/Atarimae.tsx` または `src/Yattoita.tsx`） | ファイル名とコンポジション名を新しい動画に変える。作り（画角の切り替え・BGM・終わりの場面）はそのまま使う |
| `src/direction.ts`・`src/shots.ts`（横長だけ） | 中の表を空にして、この動画の台詞に合わせて書き直す（表情・効果音・BGM・画角） |
| `src/Panels.tsx` | 図はこの動画のものに描き直す。前の動画の図は消す |
| `src/Animatic.tsx`・`src/Styleframe.tsx`・`src/Thumb.tsx`（横長だけ） | 仕組みはそのまま、中身（代表シーン・サムネイルの文字や場面）を書き直す |

- 複製しないもの：`brief.md`・`structure.md`・`script.md`・`styleframe.md`・`notes.md`（段階ごとに新しく書く）、`src/lines.json`（声を合成すると作られる）、`public/`・`out/`・`stills/`・`reference/`（素材と書き出し。`public/` の立ち絵・効果音・BGM は、前の動画のものをコピーしてよい）
- 雛形にある `notes.md` の形（段階の記録・motion-kit への提案）は、前の動画の `notes.md` を見て合わせる

## 管理人が目指していること（動画の芯）

ユーザーが折に触れて話してくれる、この家の管理人の考えです。言われたら、その言葉に近い形でここに書き足します。

- 管理人は、住人同士の絆を深めたいとか、掃除で精神を鍛えたいとは思っていない。いろんな経験をしたり成長したりすることで、**長い目で見て、その人が生きやすくなってほしい**と思っている（2026-10-23）
- それを直接は言わない。言うと胡散臭くなったり、偉そうに見えたりする。住人が「シェアハウスのおかげ」とも思わないまま、そうなっていくのを目指している（2026-10-23）
- 動画もそうなるとよい。見た人が説教されたと感じず、**ちょっとでも得したと思える**内容にする。そうでないと見てもらえない（2026-10-23、`soujibi` の台本 v1 が説教臭いと言われて）
- 台本では：めたんが答えを言い切って教えたり、「えらいわ」とほめて締めたりすると説教になる。めたんは気づくきっかけを置くだけにして、苦手なことには「一緒にやりましょう」と付き合う（`soujibi` v1 にユーザーが入れた終わり方から）

## 台本

- **元になった会話をなぞらない**：住人の会話から気づきだけを取り出し、誰にでもありそうな場面に作り直す。名前・住まい・地域・仕事・人数・金額・特定の人の話は出さない
- **伝えたいことを1文に決め、別々の角度の具体例2〜3個で見せる**（`omoikomi` から）。必要なら、ナレーションやほかのキャラを使ってよい
- **予想される反論を入れて、それに答える**
- **本筋に関係ない遊びの掛け合い（余白）を入れる**。詰め込みすぎると、聞いていて疲れる
- 研究などの裏付けはほのめかす程度にとどめ、大学名や論文名は出さない
- VOICEVOX が読み間違える言葉は、言い換えるか、ひらがなにする（例：「何」→「なに」）
- 台本は、公開する前に人が確認する

## 素材と長さを、内容の制約にしない

- 手元にある素材を前提に、案を狭めない。たとえば「立ち絵が2人分しかないから、3人目は声だけにする」のようには考えない。まず内容として一番良い形を考え、足りない素材は用意する。背景・効果音・BGM、ほかの道具やサービスも同じ
- 長さも決めない。前の動画の長さを引き継がない。長さは中身で決め、削るかどうかは「聞いていて退屈するか」で決める
- 制約に見える数字を見つけたら、それが作り手の意図なのか、雛形や前の動画から引き継いだだけなのかを確かめる

## 画面

- 立ち絵は坂本アヒルさんの素材。3人とも全身。体をシンクやコンロなどで隠さない
- 背景はみんちりえを優先する（夜・照明ありの絵）。ないときは、写真を絵に寄せて作る
- **画角を変える**（`omoikomi` から）
  - 引き（3人）が基本
  - 寄りは、決め台詞・感情が動く一言・伝えたいことの要の一言で、話す人に 1.7倍（ショートは画面が縦長なので 1.6倍）。1台詞だけ寄って、次で引きに戻す。寄りを3回より多く続けない
  - 差し込みは、仕組みや手順を説明する台詞で使う。図が主役になり、背景をぼかして暗くし、話す人を右下に小さく出す
  - 1つの画角は最低 `hold.medium`（1.5秒）見せる
- **画面のまわりに枠を付けない**。2026-10-21 までの動画は `style.ts` の `frame`（幅14px・角の丸み26px）で枠を付けるつもりだったが、内側の絵が枠の幅だけ右下にずれて、上と左にだけ黒い線が出ていた（ユーザーが公開後に気づいた）。公開済みの動画はそのままにし、新しい動画は `frame` を `{ width: 0, radius: 0 }` にする
- 細かい値は `omoikomi/styleframe.md` にあります

## 音

- BGM は OpenTracks から、ずんだもん動画でよく使われる曲を選ぶ。**シーンが変わったら曲も変える**。曲ごとの音の大きさは gain でそろえる
- **最後のあいさつは、本編と違う曲にする**
- 本編の最後の台詞とあいさつの間に、効果音「ちゃんちゃん♪」（効果音ラボ）と約3.3秒の間を置き、本編が終わったことを分かるようにする
- 曲を選ぶときは、[bgm-checks.md](bgm-checks.md)（申し立ての記録）を見る。使う曲がすべて前に申し立てなしで、流す長さもその範囲なら、確かめずに使ってよい
- それ以外は、承認の前に YouTube へ非公開でアップロードして、Content ID の申し立てが付かないか確かめる（非公開ならユーザーの許可は要らない）。結果は bgm-checks.md に足す

## 冒頭と終わり

- 冒頭は、盛り上がる一瞬を先に見せるか、事件から入るかを、構成の段階で比べて選ぶ
- **毎回、初めて見る人にも舞台と関係が分かるようにする**（2026-10-22 から）。見ている人はほぼ全員が初めての人なので、どの回も1話目として見られる。ただし、台詞の前置きで説明はしない（冒頭は短く、タイトルとサムネイルで約束した中身をすぐ見せる）。次の3つで見せる
  - **場所の文字**：最初の場面に2〜3秒、「シェアハウス・夜のリビング」のように出す
  - **名札**：それぞれ初めて出てきたときに、名前と役割を2〜3秒出す（「ずんだもん（住人）」「つむぎ（住人・後輩）」「めたん（管理人）」）
  - **事件の台詞に一言混ぜる**：伝えたいことがシェアハウスという前提に頼る回は、ツッコミの中に「みんなのリビング」「この家の住人」のような一言を入れる
  - 効いたかどうかは、視聴者維持率の最初の30秒（「イントロ」）で、前の回と比べる
- 終わりに決まった定型の場面は入れない。キャラの一言（チャンネル登録の呼びかけ）で締める
- 横長の動画は、本編が終わったら（「ちゃんちゃん♪」のあと）、3人が小さく（0.72倍）なって画面の左半分へ移り、右半分を YouTube の終了画面（登録ボタン・次の動画）に空ける。最後の一言のあと、約12秒そのまま止める
- クレジットは、その12秒の間に左下に小さく出す。`VOICEVOX:キャラ名` は必ず入れる

## ショート

- 横長の動画を切り抜かず、単体で話が通じるように作る
- 本編と組で企画する。ショートの中では本編へ誘導しない（「続きは本編で」の台詞や札を入れない）。オチで終える。「関連動画」に本編を設定し、気になった人だけが押せばよい形にする（2026-10-22 ユーザーの判断。誘導を毎回入れていたが、ショートから本編へ移る人は約0.3%と少なく、宣伝っぽい終わり方はショートそのものの見られ方を下げかねないため）
- **仮説（2026-10-24 の分析から。検証中）最初の一言に、一番おかしい所を持ってくる**。「ん？」と引っかかるずれ（大げさな反応、ずれた思い込み、意味不明な行動）で始め、説明はそれを回収する後ろに回す。よくある困りごとをそのまま言う出だしは、まっとうで引っかかりがなく、指が次へ進む
  - 根拠：飛ばされなかった割合が、ずれで始まった網戸 39%（網戸の穴で業者を呼ぶ）・鍋 37%（全員「自分の分は完璧」）・hanauta 36%（意味不明な歌）に対し、困りごとで始まった yattoita 20%（洗濯物の入れっぱなし）・sofashita 20%（リモコンがない）。sofashita は見た人はほぼ最後まで見ていて、オチ（指定席の下は落とし物の指定席）の手前で9割が去っていた
  - 試したら、分析の日（土曜の午前）に飛ばされなかった割合を比べ、`channel/analytics-log.md` に結果を書く。5本からの仮説なので、外れたら書き換える
- つかみの直後も、短い台詞でテンポを落とさない。hanauta は、歌のあと会話の説明に入った 0:07〜0:14 で、残っていた人が半分に減った
- ショートの役割は、ショート単体で面白いことと、登録者を増やすこと。本編の宣伝として考えない（ショートから横長へ来た再生は、2026-10-22 までの全期間で6回だけ）

## サムネイルとタイトル（横長）

2026-10-22 ユーザーと決定。理由と材料は [thumbnail-study.md](thumbnail-study.md)（押される割合が 1.1〜2.1% と低く、形の近い伸びているチャンネルと比べて決めた）。

- サムネイルの大きい文字とタイトルは、主張や結論ではなく、どこが変なのか（ずれ）を見せて「え、なんで？」と思わせる。答えは書かない
- **型は次の6つから選ぶ。毎回同じ型にしない**（「〇〇する奴」ばかりだと決めつけた言い方が続いて単調になる。2026-10-23 ユーザー）。案を出すときは、型の違う案を2〜3つ並べる。サムネイルとタイトルも、別の型にしてよい

| 型 | 形 | 例 |
|---|---|---|
| ① 状況の名前 | 〇〇する奴 | 通話で叫んでるのに気づいてない奴 |
| ② 期待と現実 | 〇〇したら、△△だった／左右に「本人のつもり」と「まわりから見た現実」 | 「4人で盛り上がってるつもり」／「まわりには ひとりで叫んでる」 |
| ③ ひとこと | 登場人物のセリフをそのまま使う | 「買ったら」って書いたのに「買ったの！？」 |
| ④ 問いかけ | 見る人も思っている疑問を、ずんだもんが口にする | 全員でやる掃除の日って、いるのだ？ |
| ⑤ 逆説 | 〇〇な人ほど△△ | 「荷物多すぎ」と笑う人ほど、借りに来る |
| ⑥ 具体的な数字 | 一目で分かる数字を入れる | 冷蔵庫の禁止の貼り紙が、13枚になったのだ |

- 絵だけで出来事が分かるようにする。場所が分かる背景に、その回だけの小道具を必ず写す。人物は2人前後で、気持ちに温度差をつける（平気なずんだもんと、焦る相手など）。顔は大きく
- 文字は太く、色を変えるのは1〜2語。小さい文字は関連動画の欄の大きさ（幅168px）では読めないので、なくても伝わるようにする
- サムネイルとタイトルで同じことを言わない。サムネイルは場面、タイトルはずれや気づき
- 作ったら、スマホのホーム画面の大きさ（幅360px）と関連動画の欄の大きさ（幅168px）に縮めて確かめる

## タイトル・概要欄などの公開文

- タイトルは、中身を表す一言のあとに【ずんだもん・めたん・つむぎ】を付ける。一言は、ずんだもんの口調（〜なのだ）にすることが多い
- 概要欄やチャンネル説明は、見る人に向けて書く。どんな動画か、何が面白いか、自分向けかを、くだけた語り口で書く。「特定できないように作り直しています」のような作り手側の方針や、仕様書のような列挙は入れない
- 最初の1文で、どんな動画かを伝える。規約で必要な一文（非公式の二次創作であることなど）は、最後に短く添える
- アップロードのとき、場所の自動表示はオフにする

YouTube の公式情報にもとづく運営の方針は、[youtube-guide.md](youtube-guide.md) にあります。
