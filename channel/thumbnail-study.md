# サムネイルと題名の見直し

2026-10-22 開始。横長の動画は、入口のほぼ全部がホーム画面のおすすめ（約95%）なのに、サムネイルが押される割合が 1.1〜2.1% と低い（`channel/analytics-log.md`）。押された後は見てもらえている（思い込みは30秒で63%残る）ので、次の動画からサムネイルと題名に力を入れる。

## 計画（2026-10-22 ユーザーと決定）

1. 今の4本を並べて見直す（スマホのホーム画面・関連動画の欄の大きさに縮めて）
2. 形の近い、伸びているチャンネルのサムネイルと題名を集め、同じチャンネルの中で伸びた回・伸びなかった回を比べる。YouTube 公式の手引きも読み直す
3. このチャンネルの型とチェックリストを決め、`channel/zundamon-guide.md` に書く（AI が案を出し、ユーザーが選ぶ）
4. サムネイルを3案まで書き出し、ホーム画面に似せた絵の中で見比べられるようにする。横長は「テストと比較」で3案を試す前提にする
5. 練習として atarimae（1.1%）のサムネイルと題名を作り直し、「テストと比較」にかける（公開中の動画を変えるので、型ができた時点でユーザーに確認する）

その先：企画の最初（ブリーフ）で題名とサムネイルを先に考え、「サムネイルで約束できる、ひと目で分かる場面があるか」をネタ選びの基準に加える。

材料の置き場所（git に入れない）：`channel/reference/own/`（自分の4本の縮小と比較の絵 `sheet.png`）、`channel/reference/thumbs/`（他のチャンネルのサムネイルと `notes.md`）

観察（見て分かること）：
- 4本とも同じ配置（上に黄色の大きい文字と白の小さい文字、左下にずんだもん、右に1人、ぼかした部屋）。チャンネルとしてはそろっているが、どの回も同じ絵に見え、回ごとの違いが伝わりにくい
- 関連動画の欄の大きさ（幅168）では、小さい文字はほぼ読めない。読めるのは大きい文字と顔だけ
- 3本は、サムネイルの文字が題名の言い換えになっている（同じことを2回言っている）。hitorigoto だけ、サムネイル（場面）と題名（気づき）で役割を分けた
- 大きい文字が、場面ではなく結論や主張になっている。atarimae は答え（家がきれいになったから）まで言ってしまい、押す理由が残らない
- 何が起きている場面かが絵から分からない。キャラは並んで立っているだけで、出来事（物・相手・状況）が写っていない。物が写っているのはプリン（カップ）だけ
- 題名の後ろの【ずんだもん・めたん・つむぎ】は長く、初めて見る人（ほぼ全員）にとっては押す理由にならない。スマホでは題名の後半が切れることがある

推測（確かめたいこと）：
- 一番押された思い込み（2.1%）は、「難しそう」という、誰でも言ったことのある一言をかぎかっこで出している。身に覚えのある言葉が効いたのかもしれない
- 一番低い atarimae（1.1%）は、答えまで書いた長い文字。読み切れないうえに、答えが分かってしまう

## 2a. YouTube 公式の手引き（2026-10-22 読み直し）

[12340300](https://support.google.com/youtube/answer/12340300)（タイトル・サムネイル）
- サムネイル：登録していない人向けには、驚きなど誰でも共感できる表情や感情に焦点を当てる。三分割法。文字は読みやすい書体で。どの端末でも大きく見えるように。複雑にしすぎない、色や構成をやりすぎない。古いサムネイルも更新してよい
- タイトル：内容を正確に、簡潔に。いちばん大事な言葉を前に、シリーズ名などは後ろ。検索されるタイトルか、興味を引くタイトルかを選ぶ（このチャンネルはおすすめが入口なので、興味を引く方）
- 効果は、公開後24時間のクリック率を「ホーム・おすすめ」と「登録チャンネル」で分けて見る

[16391400](https://support.google.com/youtube/answer/16391400)（テストと比較）
- 横長だけ。パソコンの Studio から。最大3案（タイトルのみ／サムネイルのみ／両方）。「上級者向け機能」の資格が要る（身分証の確認が済んでいるか確かめる）
- 勝ちは総再生時間で決まる（クリック率ではない）。数日〜2週間。表示回数が少ないと「ベスト」が出にくい。案どうしが似すぎていると差が出にくい
- テスト中にタイトルやサムネイルを変えると止まる。古い動画から試すとチャンネル全体への影響が少ない
- このチャンネルの規模では、1本の表示回数が数千回なので、はっきりした結果は出にくいかもしれない。案は大きく違うものにする

## 2b. 形の近いチャンネルの比べ（2026-10-22）

6チャンネル・66本（ずんだみん、だももだも、がっこうずんだもん、ずんだのーべる、あぎりさんぽ、ずんだもんと学ぶ不動産）。詳しい表は `channel/reference/thumbs/notes.md`、伸びた回と伸びなかった回を並べた絵は `channel/reference/thumbs/compare.png`（どちらも git に入れない）。

注意：上位の回は 2022〜2023 年に集中していて、チャンネルの勢いや時期の影響が大きい。同じサムネイルの再投稿が 48.5万回と 12.5万回に分かれた例もある。型だけで決まるとは考えない。

伸びた回に共通する型（観察）：
1. 題名とサムネイルの文字が「状況の名前」で、その中にずれがある（「事件起きてるのに全然仕事辞めない奴」「婚活パーティーで上司と鉢合わせた」「クソ回線で会議する奴」）。主張や結論ではない
2. 誰でも知っている場面（コンビニ、Web会議、入試、賃貸）。伸びなかった回は内輪の話や、元ネタを知らないと分からない話が多い
3. 絵だけで出来事が分かる。場所が分かる背景と、その回だけの小道具や仕掛け（エナドリの山、時計 21:10、頭の上の数字、燃える車）。伸びなかった回は、同じ背景に立ち絵を並べただけか、文字がない
4. 人物は2人前後で、気持ちの温度差がある（平気な顔のずんだもんと、焦る相手）。顔が大きい
5. 文字は太いゴシックで、色を変えるのは1〜2語だけ
6. 先頭の【】は、伸びた回では中身のフック（【Google入社試験】）、伸びなかった回ではシリーズ名（【日常】）や【新作】の飾り

このチャンネルとの違い：
- このチャンネルのサムネイルの文字は「主張・結論」（「だいたい思い込み」「家がきれいになったから」）。伸びている所は「状況の名前」（「〇〇する奴」）
- このチャンネルは、ぼかした部屋に立ち絵が立っているだけで、出来事が写っていない
- 不動産チャンネルのシェアハウス回（4.6万〜9.5万回）は、左右の対比（期待した暮らし／現実の不満）。「プライバシー皆無」「騒音」「金銭トラブル」など、シェアハウスの不満そのものが見出しになっている
