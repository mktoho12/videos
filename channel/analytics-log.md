# アナリティクスの記録

YouTube Studio の数字を、見るたびにここへ書き足す。1回ごとの印象ではなく、同じ数字が回を追ってどう動いたかで判断するための記録。

- 書き方：見た回ごとに、下の表へ1行ずつ足す（行は消さない、古い行を書き換えない）。「集計日」は Studio の集計が済んでいる最後の日、「見た日時」は実際に開いた日時
- 見られなかった数字は「—」。推測で埋めない
- 表のあとの「その回の読み取り」に、気づいたことと、次の動画で変えたことを短く書く
- 分析の日は**毎週土曜の午前**（2026-10-24 ユーザー決定。1週間の振り返りを兼ねる）。その日に Claude がまとめて読み、ここに書いて報告する
- 「公開◯日目」は、集計日 − 公開日（公開日の分まで集計済みなら0日目）。集計前でリアルタイムの欄だけを読んだ数字は「速報」と書く。同じ「公開◯日目」どうしで動画を比べられるように

## その回の読み取り

### 2026-10-22 朝（集計は 10-20 まで）
- 視聴の約8割がショート。ショートから本編へはほとんど移っていない（網戸→思い込み 約0.3%）。ただ、移ってきた人の平均視聴時間は 2:52 と長い
- 横長のサムネイルのクリック率が 1.7〜2.2% と低め
- yattoita は冒頭でスワイプされやすい（視聴を継続 20%。網戸・鍋の半分）
- 終了画面のクリック率は全動画 0.0%。「視聴者が見ているチャンネル」はデータ不足
- 次の動画で変えたこと：初めて見る人にも舞台と関係が分かるようにした（hitorigoto）。ショートの中で本編へ誘導するのをやめた（hanauta）

### 2026-10-22 夜（集計は 10-21 まで）
- 日別の山は、公開した日に立つ。10-21（atarimae・yattoita）は前日の半分以下に下がった。2本とも出だしが弱い（atarimae はクリック率 1.1% で、ブラウジングからほとんど入られていない。yattoita は視聴を継続 20%）
- 朝の動画ごとの数字は、集計前の速報を含んだ「公開後の最新」だったので、夜の値と並べても伸びは比べられない（朝夜でほぼ同じなのはそのため）。直近48時間のリアルタイムでは、網戸 592・プリン 467・思い込み 392・yattoita 345 とまだ見られていて、鍋 85・atarimae 23 は止まりかけ。次回からは、動画ごとの数字は集計済みの値と速報を分けて書く
- 思い込みは 30秒で 63% 残り、プリン（46%）より出だしが良い。最後まで残るのは2本とも 2割台
- 横長の入口は、ほぼ全部ブラウジング（ホーム画面のおすすめ）。クリック率 1.1〜2.1% が伸びの天井になっている。サムネイルと題名がいちばん効きそう
- hanauta（誘導なしのショート）が公開1時間あまりで 835回。網戸・鍋と同じかそれ以上の出だし。視聴を継続などは集計後（10-24 ごろ）に見る
- プリンの30秒の値が、朝の 51% から 46% に変わった。朝は見た人の読み方、夜は Studio の文言と一致を確かめた値。夜の値を正とする

### 2026-10-23 夜（リアルタイムだけ。集計済みの数字は見ていない）
- 直近48時間：1,764回。直近60分：19回。動画ごとの48時間は、hanauta 1,209・思い込み 356・hitorigoto 60・プリン 56・atarimae 54・網戸 16・鍋 6・yattoita 4。直近60分は、思い込み 7・プリン 6・hanauta 3 など
- ユーザーの気づき：hanauta の山以外の、静かな時間帯の底が上がっている。グラフから読むと、山の前は1時間に 5〜10回ほど、山のあとは 20〜35回ほどで、3倍くらい。48時間の前半と後半は同じ時刻を1回ずつ含むので、時間帯による差ではなさそう
- 底を支えているのは横長（思い込み・プリン）。どちらも公開から3〜4日たっても、直近60分に6〜7回見られている。山のあとに上がったので、hanauta を見た人がチャンネルの横長へ流れた可能性と、横長が「ブラウジング」に出続けている可能性がある。どちらなのかは、集計後（10-24 以降）に思い込みの入口（ブラウジング／チャンネルページ／関連動画）と、hanauta からの移動の数で確かめる
- まだ2日分なので、明日も底が保たれているかを見る。保たれていれば、チャンネル全体の日別の視聴回数（山の日を除いた分）が上がっていくはず

### 2026-10-24 朝（集計は 10-22 まで。第1回の週の振り返り）
- 1週間：開設5日で 5,162回・19.6時間・登録者7人。日ごとの山と谷は、その日のショートの当たり外れでほぼ決まる（yattoita の 10-21 だけ 730回）
- 横長の課題は入口：クリック率が 思い込み 2.4%・プリン 1.4% → atarimae 0.9%・hitorigoto 0.7% と、後の2本で落ちている。30秒で残る割合は4本とも半分前後で大差ない。中身より、サムネイルとタイトルで負けている
- hanauta（誘導なし）は、平均再生率 55.6%・最後に残る割合 約28% で、4本のショートで一番見られた。飛ばされなかった割合は 36.2% で、網戸・鍋と同じくらい。大きく減るのは 0:07〜0:14（冒頭の歌が終わり、会話に入るところ）
- 夜中の底上げ（10-23 夜の宿題）は「横長がおすすめに出続けている」ほうだった。思い込みの直近48時間 368回のうち 98.9% がブラウジング。ショートから横長へ来た再生は、全期間でチャンネル全体6回だけ。ショートから横長へ流す形はほぼ機能していない。横長は、おすすめに乗れるかどうか（＝クリック率）で伸びる
- ショートから本編へ移った数は、Studio のどこにも出ていない。誘導なしにした影響は、この数字では測れない
- sofashita は9時間あまりで約1,170回・登録者+1。ただし飛ばされなかった割合が 19.5%（yattoita 並み）。見た人はほぼ最後まで見る（0:34／0:37）。冒頭の数秒で分かれていると読める。冒頭は、hanauta の歌のような耳を引く出だしがない
- soujibi は公開2日目でまだ9回（表示 23回）。判断は来週、思い込み・プリンと同じ「公開◯日目」で比べてから
- 次に見ること（10-31 土）：sofashita の確定値（飛ばされなかった割合・平均再生率）、soujibi のクリック率と維持率、思い込みのおすすめからの再生が続いているか
