## motion-kit への提案

motion-kit に還元したい知見を書く。動画固有の文言・ブランド・素材は書かない。

| 種別（工程 / 文法 / 部品 / 雛形） | 内容 | 根拠（この動画で何が起きたか） |
|---|---|---|
| 雛形 | brief.md の任意項目に「再生のされ方」を足す（ループの有無、前後に別コンテンツが挟まるか、冒頭と末尾をどうつなぐか） | ループ再生が前提の掲示用動画で、この項目が構成（入りと締め）を大きく左右した。雛形に欄がなく、自前で見出しを足した |
| 雛形 | brief.md に「補足要素（候補）」の欄を足し、構成案の比較軸にできるようにする | 候補が複数あり、段階1の案の分け方がそのまま補足の選択になった |
| 工程 | workflow.md 段階0の必須項目「参考動画」に「なし」も可と明記する | この動画は参考動画なしで確定した。必須のままだと、ゲートを通ってよいか迷う |
| 工程 | ブリーフを別セッション（motion-kit 側）で詰めて videos 側へ転記する流れを、workflow.md か README に書く | 今回はセッションをまたいで brief が届いた。転記元と確定の証跡を notes に残す必要があった |
| 雛形 | README の複製例に、動画ディレクトリの置き場所（videos リポジトリ直下の `<slug>/` か `videos/<slug>/` か）を明記する | videos の CLAUDE.md の「`videos/<slug>/`」がリポジトリ直下を指すのか、サブディレクトリを指すのか読み取れなかった |
| 工程 / 部品 | videos から motion-kit を `file:`（symlink）で参照すると、motion-kit 側のファイルが motion-kit/node_modules の remotion・react を掴み、別インスタンスになりうる。videos 側の remotion.config.ts で alias して回避した。motion-kit の README に推奨設定として載せるか、peerDependencies にする | 導入時に対処が必要だった（tokens だけなら実害はないが、部品を使い始めると hooks が壊れる） |
| 部品 | motion-kit の package.json に `exports` がなく、`motion-kit/src/tokens` のように内部パスで import することになる。公開口（`exports`）を決める | 段階3以降で tokens を import するときの参照先が曖昧 |
| 工程 | 「完成した動画は motion-kit のタグを package.json で固定」と「共有 package.json 1つ」が両立しない。動画ごとに package.json を持つか、完成時に固定の仕方を決める必要がある | videos をリポジトリ直下の共有 package.json で始めた |
| 文法 | 「同じ画面内で系統を3種類以上混ぜない」の「画面」がシーン単位か動画全体かを明記する | この動画はシーン内では2系統、動画全体では3系統になった |
| 文法 | hold の `long`（2.5秒）より長く主メッセージを見せたい用途（掲示・ループ再生）がある。用途別の hold の目安を足す | 通りすがりに見る掲示用なので、主メッセージを約6秒出す |
| 部品 | @remotion/google-fonts の日本語書体は、weights を絞っても約240リクエストになる。使う文字だけの subset にするか、ローカルのフォントファイルを置く方針を決める | Zen Maru Gothic で still 書き出しのたびに警告が出た |
| 雛形 | Animatic.tsx の SceneCard は、文字が折り返すと左寄せになり、カードの中で中央にそろわない。`textAlign: center` を足す | 16文字の補足文が2行に折り返し、左に寄った |
| 雛形 | Animatic.tsx の複製手順で、tokens の参照先を `motion-kit/src/tokens`（file: 参照時）と具体的に書く | `../../tokens` の書き換え先を自分で決める必要があった |
| 部品 | 「シーン開始＋遅れ＋所要時間＋イージングトークン → 0〜1」の小さな関数（この動画では `src/motion.ts` の `progress`）と、その zod スキーマ（`tweenSchema`）を自前で書いた。2本目でも書くことになれば kit に昇格する候補 | 本実装で、動きを props に出すたびに同じ形が必要になった |
| 文法 | linear で流れ続ける動き（波・スクロール）の速さのトークンがない | 熱の波の流れる速さを動画固有の値で置いた |
| 文法 | シーンの長さが短いと、hold の組み合わせ（例: slow＋beat）が収まらないことがある。締めの推奨形を決めておく | S5（1.0秒）で styleframe.md の予定を削った |
| 工程 | 段階6の書き出し設定の既定（コーデック・CRF・ピクセル形式・色空間）を workflow.md か remotion.config.ts に置く | Remotion の既定では yuvj420p（フルレンジ）で出力され、テレビ再生向けに指定し直した |
| 工程 | 「完成した動画は motion-kit のタグで固定」は、motion-kit にタグがまだないと実行できない。この動画は v0.1.0 のタグが付いたら固定する | 完成時点で motion-kit が未コミット・タグなしだった |
