# 構成（シーン表）

> 段階1。AI が秒数付きのシーン表を 2〜3案つくり、人が1案を選ぶ。

- ブリーフの尺: 決めない（中身で決める）
- 作成日: 2026-10-22

秒数は目安で、制約ではない。台本を合成した長さで決まる。話す速さは 1.15倍。

## どの案にも共通すること

- **舞台と関係を見せる**（決め事、2026-10-22）：最初の場面に場所の文字（「シェアハウス・夜のリビング」）を2〜3秒。それぞれ初めて出てきたときに名札（「ずんだもん（住人）」「つむぎ（住人・後輩）」「めたん（管理人）」）。台詞の前置きでは説明しない。共有の場所だと分かる一言は、つむぎのツッコミに入れる（「ここ、みんなのリビングですよ！」）
- **画角**：引き（3人）が基本。寄りは、感情が動く一言と、伝えたいことの要の一言。差し込みは、仕組みを見せる図
  - 聞こえ方の図：ヘッドホンの中（相手の声＋ずんだもんの声）と、外（ずんだもんの声だけ）を左右に並べる
  - リビングの図：誰かがいると、まわりの部屋から人が出てくる。こもると、扉が閉まったまま
- **反論**：ブリーフの2つ（「禁止なのだ？」／「好きにさせて」）を、案ごとに違う場所に入れる
- **冒頭は2通りから選ぶ**（どの案にも付けられる）
  - **冒頭X「先出し」**：途中の盛り上がる一瞬を2〜3秒見せる → タイトル → 本編の頭
  - **冒頭Y「事件から」**：先出しなしで、いきなり事件から入る
- **余白**：本筋と関係ない掛け合いを1〜2か所（例：ずんだもんのゲーム内の役回りの話、つむぎが見ている動画の中身）
- **サムネイル**：ヘッドホンで叫ぶずんだもんと、後ろで固まる2人。大きい文字は短い一言（例「ひとりで叫んでる？」）で、答えは書かない
- **終わり**：キャラの一言（チャンネル登録の呼びかけ）→「ちゃんちゃん♪」と間 → 本編と違う曲で3人が左へ寄り、右半分を終了画面に空ける（`zundamon-guide.md`）

## おすすめ

**案A、冒頭Y（事件から）**。

- 冒頭の事件（ヘッドホンで叫ぶずんだもん）が、そのままサムネイルの絵になる。サムネイルで約束した中身を最初の20秒で見せられる（YouTube 公式の「イントロは短く、約束をすぐ果たす」）
- ずんだもんが「叫ぶ側 → 聞かされる側 → ひとりになる側」と立場を変えるので、例が3つあっても流れが単調にならない
- メッセージの後半「みんなの場所でいられること」を、最後の場面（人が集まってくる）の絵で見せて終われる
- 案B は冒頭の絵が弱く、サムネイルとずれる。案C は禁止の話から始まり、前の回のオチとも形が近い
- 冒頭X（先出し）は、S1 の叫び自体が一目で分かる事件なので、要らないと考えます
