# 構成（シーン表）

> 段階1。AI が秒数付きのシーン表を 2〜3案つくり、人が1案を選ぶ。
> 合計秒数はブリーフの尺に合わせる。

- ブリーフの尺: 30〜60秒（ショート、9:16、ループする）
- 作成日: 2026-10-19

どの案も、画面は「流し（大鍋）」を上半分に大きく描き、3人を下半分に並べる。字幕は真ん中寄り。秒数は目安で、台本を合成した長さで決まる。

## 案A: 時系列で積み上げる（鍋が残る → 押しつけ合い → 1.1倍 → オチ）

| # | 開始 | 終了 | 秒数 | 画面に出すもの | 狙い |
|---|---|---|---|---|---|
| S1 | 0.0 | 2.0 | 2 | 流しに大鍋が1つ。台詞なし、効果音だけ | つかみ。ループのつなぎ先（最後のコマと同じ絵） |
| S2 | 2.0 | 12.0 | 10 | 3人が順に「自分の皿は完璧に洗ったのだ」「あーしもです」「わたくしも」 | 全員ちゃんとやっている（補足1） |
| S3 | 12.0 | 24.0 | 12 | 「じゃあこの鍋は？」→「ボクのじゃないのだ」「あーしのでもないです」。テロップ「1日目 → 2日目 → 3日目」で鍋が残り続ける | 誰の分でもない物が残る |
| S4 | 24.0 | 34.0 | 10 | めたん「自分の分の1.1倍でいいのよ」。「1.1倍」のテロップ | メッセージ（補足2） |
| S5 | 34.0 | 42.0 | 8 | ずんだもんがフタの取っ手だけ洗って「1.1倍なのだ！」→ つむぎ「取っ手だけ！？」。最後は鍋が流しに残ったままの絵に戻る | オチ。最後のコマが S1 の絵につながり、また頭から始まる |
| | | | **42** | | |

ループ：オチのあと、鍋だけが残った流しの絵で終わる → 頭の「流しに鍋が1つ」に戻る。「結局、鍋は残ったまま」という皮肉が、ループでくり返される。
